# Clew

[![CI](https://github.com/m2selfA/clew/actions/workflows/ci.yml/badge.svg)](https://github.com/m2selfA/clew/actions/workflows/ci.yml)

Public repository: [m2selfA/clew](https://github.com/m2selfA/clew); the current normal release is [`v0.2.1`](https://github.com/m2selfA/clew/releases/tag/v0.2.1), with all downloads also listed on [GitHub Releases](https://github.com/m2selfA/clew/releases). Windows CI runs natively on `windows-2022`; Linux release compatibility is built and verified inside `manylinux2014_x86_64` with a hard glibc 2.17 container gate plus final ELF `GLIBC_*` symbol-version check. Clew `0.x` builds are published as normal GitHub Releases even though Windows/macOS are unsigned; the first fully Code Signed + notarized cross-platform release will deliberately move to a new major version (`1.x` or later).

一根穿过 NAT 的线：合作者打开一份预配置的 Site Kit 并双击，你的 agent 就可以在对方机器上读文件、改文件、跑命令、转发端口、走代理、传文件。人在 GUI 里点；agent 走本机 MCP。

Windows `0.2.x` 起默认走零终端入口：Controller 机器解压 Release 后双击 `Clew Launcher.exe`，在 GUI 中直接创建可分发 Site Kit、勾选 Read/Write/Shell/TCP 权限并启停本机 MCP；MCP URL 可直接复制为 `http://127.0.0.1:4877/mcp`。收件人完整解压 Site Kit 后只需双击根目录 `Clew.exe`，再选择“Use this computer”或“Help nearby computers connect”；后台 `clew.exe` 以隐藏 console 的方式启动，Host 窗口关闭时继续缩到 tray。Windows/macOS 的 `0.x` unsigned 状态会明确显示，不冒充 signed release。
