# Clew

一根穿过 NAT 的线：合作者打开一份预配置的 Site Kit 并双击，你的 agent 就可以在对方机器上读文件、改文件、跑命令、转发端口、走代理、传文件。人在 GUI 里点；agent 走本机 MCP。

Architecture v1.5 规划文档见 [docs/README.md](docs/README.md)。V0–V1.3 已完成 stable IDs/state/proto、Controller 单实例 + Local API/GUI、ControllerKey/DeviceKey、signed Site Kit + Host lifecycle/naming，以及 iroh direct/public-relay + Target↔Controller Noise InnerSession E2E；V1.4 的 Controller-owned control state、network enrollment、bounded `Read`、Activity、backup/Recovery Review 与 GUI/CLI surface 已完成，并已有 Windows 双机真实 Read、Linux foreground/live revoke，以及 macOS Aqua Controller/Host tray + Read 真运行证据。**V1 release gate 已关闭，当前可对外试用；V1.25 Distribution Studio 已封板：Outfit schema/library/CLI、`clew invite --outfit`、bounded PNG/SVG distribution、Controller Studio editor/live preview，以及 Host imported app/tray/logo/key-visual runtime projection均已通过 Windows + macOS desktop acceptance。V1.5a/b/c-1/c-2 已完成 same-Site LAN discovery、Controller-signed helper lease、opaque Target↔Controller InnerSession tunnel、sealed-to-Controller first enrollment、active no-public DeviceKey InnerSession/Read，以及可见 Host runtime 的可取消后台重试/任意启动顺序；forced-unreachable-direct 的真实 iroh+mDNS enrollment + Read 在 cap00 已通过。V1.5c-3 进一步实现 `nearby-connection.clew` fallback：在 multicast/mDNS 被 VM/企业网阻断时，用户只需复制/拖入一个 Controller-signed routing hint，真正 tunnel 仍必须现场 fresh helper lease；cap00 no-mDNS enrollment+Read 已通过，正在用 macos-3dv0 exact commit 闭平台 gate，之后进入 multiple-helper failover/resume。** 已裁定边界与实施 checklist 见 [docs/06-gaps.md](docs/06-gaps.md)。

正式开发进度与下一开发块统一记录在 [docs/DEVELOPMENT_CHECKPOINT.md](docs/DEVELOPMENT_CHECKPOINT.md)；每完成一个 coherent block，都同步更新该文档后再进入下一块。
